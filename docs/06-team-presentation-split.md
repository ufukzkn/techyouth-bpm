# Team Presentation Split

The team split is flow-based. Each person owns a user journey end to end, including UI, API usage, state, tests and explanation.

## Person 1: Access And Shell Flow

- Login page.
- Session storage with user and role.
- Protected app layout.
- Header and left menu.
- Dashboard and settings.
- Role-based menu visibility.

Presentation angle: how users enter the system and how role information shapes the interface.

## Person 2: Form Flow

- Form designer.
- Custom field components.
- Field ordering.
- Required, type-based and dependent validation.
- Dynamic form runner.
- Submit loading/success/error states.

Presentation angle: how a form is represented as data and rendered dynamically.

## Person 3: Process And Review Flow

- Process start.
- Task creation.
- My tasks.
- Approve/reject actions.
- Process detail.
- State machine and audit log.
- Code review narrative.

Presentation angle: how BPM is modeled with statuses, tasks, actions and traceable transitions.
